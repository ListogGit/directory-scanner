# Directory Scanner

Простой инструмент для анализа структуры проектов и генерации отчетов.
> Создан на 90% нейросетью просто потому что понадобилось срочно для моих целей

## Возможности

- Автоматическое определение типа проекта (Godot, Node.js, Python и другие)
- Древовидное отображение структуры папок и файлов
- Подсчет строк кода и статистика по типам файлов
- Умное игнорирование служебных папок (node_modules, .git и т.д.)
- Генерация текстовых отчетов с детальной информацией

## Использование

Требуется Node.js версии 12 или выше.

- Запустите скрипт: ```node scan-directory.js```
- Введите путь к проекту (или оставьте пустым для текущей папки)
- Получите отчет в консоли и в файле

Отчет сохраняется в файле с именем **project_report_[имя_папки]_[дата].txt**

# Настройки  
Основные настройки находятся в начале файла в объекте CONFIG:

- EXCLUDE_DIRS - папки для игнорирования
- MAX_DEPTH - максимальная глубина сканирования
- MAX_FILE_SIZE - максимальный размер файла для отображения содержимого
- MAX_LINES - максимальное количество строк для отображения
